# Добавить MD в контекстное меню Windows

> **Языки документации**: [简体中文](README.md) · [繁體中文](README-zh-TW.md) · [English](README-en.md) · **Русский** · [日本語](README-ja.md) · [한국어](README-ko.md) · [Français](README-fr.md) · [Español](README-es.md) · [العربية](README-ar.md)

Добавляет пункт «Создать файл Markdown (.md)» в контекстное меню проводника Windows.

## Возможности

После импорта файла реестра вы сможете:

- Щёлкнуть правой кнопкой в любой папке → **Создать** → выбрать файл Markdown
- Связать расширение `.md` с типом файла Markdown

## Использование

1. Выберите файл `.reg` для вашего языка системы из таблицы ниже
2. Дважды щёлкните по файлу
3. Нажмите **Да** в диалоге подтверждения
4. Готово, когда появится сообщение об успешном добавлении в реестр

Перезагрузка не требуется. Обновите проводник или откройте папку заново.

## Требования

- Windows 7 и выше
- Требуется подтверждение администратора (запрос UAC)

## Сведения о реестре

Этот инструмент изменяет следующие ключи реестра:

```
HKEY_CLASSES_ROOT\.md
HKEY_CLASSES_ROOT\.md\ShellNew
HKEY_CLASSES_ROOT\MarkdownFile
```

В частности:

- Регистрирует расширение `.md` и MIME-тип `text/markdown`
- Включает пункт **Создать** в контекстном меню через `ShellNew`
- Задаёт отображаемое имя типа файла в проводнике

## Удаление

Чтобы удалить эту функцию, создайте и запустите файл `.reg` со следующим содержимым (сохраните как `Remove-MD-Context-Menu.reg`):

```reg
Windows Registry Editor Version 5.00

[-HKEY_CLASSES_ROOT\.md\ShellNew]

[HKEY_CLASSES_ROOT\.md]
@=-
"Content Type"=-
"PerceivedType"=-

[-HKEY_CLASSES_ROOT\MarkdownFile]
```

> **Примечание**: если другое приложение связало `.md` с другим типом файла, после удаления может потребоваться сбросить приложение по умолчанию.
